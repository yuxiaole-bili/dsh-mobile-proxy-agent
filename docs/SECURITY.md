# 安全说明（Security）

本仓库是**脱敏镜像**，线上运行目录（`%LOCALAPPDATA%\dsh-gui-forward`）才是原始文件。
每次同步都会跑一遍脱敏与复核，规则与结果如下。

## 1. 凭据

| 项目 | 处理 |
|---|---|
| capability key（`cap.key`） | **不进入仓库**。代码里只有 `DEFAULT_KEY` 占位符；运行时从本地文件读或由环境变量注入 |
| 请求鉴权 | 代理只认 `?k=<key>` 或 `dshcap` cookie；`/__health` 不需要密钥 |
| 日志 | **已修复**：历史调试行里曾出现明文 key（3 处），现已替换为 `<REDACTED>`；当前代码不打印 key |
| 仓库扫描 | 正则扫描 `cap.key` 明文、`dshcap=`/`?k=` 非占位值、`sk-*`/`ghp_*`：**0 命中** |

## 2. 网络地址

仓库里所有内网与 Tailscale 地址均为占位符：

| 占位符 | 含义 |
|---|---|
| `<PC-LAN-IP>` | 运行代理的电脑局域网地址 |
| `<SRV-LAN-IP>` | 转发/服务器局域网地址 |
| `<TAILSCALE-IP>` | 服务器 Tailscale 地址 |
| `<PHONE-TS-IP>` | 手机 Tailscale 地址 |

`plugin/index.js` 里的 `100.64.0.0` **不是地址**，是 CGNAT 网段判断，故意保留。

## 3. 内存与资源上限

| 资源 | 上限 | 说明 |
|---|---|---|
| API 缓存 | `API_CACHE_MAXBYTES`（默认 512 MB，可调） | 实测 132.8 MB / 1677 文件，LRU + 过期淘汰，**有界** |
| 缓存条目 TTL | 会话 20 s / 运行中 4 s / 历史页 7 天 / 目录类 60 s | 目录类为手机端降延迟新增 |
| 客户端错误数组 | `S.errors` 30 条、`__dshHotErrors` 60 条 | 超出丢最旧；防止长跑无限增长 |
| 客户端注入元素 | 固定 1 个折叠按钮 + 0/1 个覆盖层关闭按钮 | 关掉即移除，不累积 |

## 4. 如何自查

```powershell
python security_audit.py      # 扫描仓库/热补丁/日志里的密钥与地址，报缓存与进程内存
python final_security_check.py # 命中明细 + 线上/仓库一致性（脱敏感知）
```

## 5. 已知边界

- 热补丁文件由代理**按请求实时读取**，改文件即生效；因此**不要把密钥写进热补丁**。
- 日志会记录 API 路径与耗时（不含密钥）；如需长期留存，建议定期轮转。
- 本仓库不含 APK 签名材料；`android/` 仅为源码摘录。
