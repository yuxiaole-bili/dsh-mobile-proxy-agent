# 网页版使用方式（iPhone / iPad / 任意浏览器）

**不需要装 APK**。手机浏览器直接开代理地址就是完整版 DSH，交互层（消重叠、折叠按钮、
长按展开、覆盖层 ✕、代码高亮）对 iOS Safari 同样生效。

## 一、完整版（推荐）

1. 让手机和电脑在**同一个局域网**（或都接入同一个 Tailscale 网络）
2. Safari 打开：
   ```
   http://<电脑IP>:19390/?k=<你的访问密钥>
   ```
3. 首次打开后密钥会写入 cookie（`dshcap`），之后可以直接开 `http://<电脑IP>:19390/`

**添加到主屏幕**（像 App 一样用）：
Safari → 分享 → 「添加到主屏幕」。之后从桌面图标打开即是全屏（无地址栏）。

## 二、轻量版（消息 + 发送）

网络差或只想发消息时用轻量版，页面极小、加载快：

```
http://<电脑IP>:19390/m
```
或带上密钥：`http://<电脑IP>:19390/m?k=<你的访问密钥>`

（Android APK 启动页里的「轻量版（消息 + 发送）」就是打开这个地址。）

## 三、iOS 使用注意

| 事项 | 说明 |
|---|---|
| 视口 | 页面已带 `viewport: width=device-width, initial-scale=1`，iOS 正常缩放 |
| 刘海 / 底部横条 | 若内容贴边，可把 Safari 转横屏再转回，或添加到主屏幕获得安全区留白 |
| 语音输入 | iOS 用键盘自带的听写（麦克风键），不走 APK 的原生语音通道 |
| 后台 | iOS 会冻结后台标签页，长任务期间保持页面在前台；任务在服务端继续跑 |
| 复制文件 | 文件预览/下载走 `/f`、`/dl`，Safari 会交给「文件」App 保存 |
| 热补丁 | 交互层与高亮由代理注入；`?no-hot=1` 可临时关闭 |

## 四、连不上时排查

1. 电脑上代理是否在监听：访问 `http://<电脑IP>:19390/__health`，应返回 `proxy-ok`
2. 是否同一网段：手机浏览器开 `http://<电脑IP>:19390/__health`（此路径免密钥）
3. 密钥是否正确：错误密钥一律返回 `403 access key required`
4. 走 Tailscale 时用服务器的 Tailscale 地址 + 转发端口（见 `docs/SETUP.md`）
